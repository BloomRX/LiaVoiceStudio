# LiaVoiceStudio — laboratório de avaliação de voz

Repositório de pesquisa para avaliar tecnologias e motores de geração de voz que possam ser considerados para o ecossistema Lia. A presença do estudo não significa que exista integração funcional na aplicação.

Consulte [`docs/BRAND-STANDARDS.md`](docs/BRAND-STANDARDS.md) para princípios comuns de marca. `AGENTS.md` define limites de segurança, licenças e consentimento.
